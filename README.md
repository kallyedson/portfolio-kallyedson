## Temas claro e escuro

O portfólio possui suporte aos temas claro e escuro.

A escolha realizada pelo visitante é salva no `localStorage`. Dessa forma, quando a página é atualizada ou acessada novamente no mesmo navegador, o tema selecionado é mantido.

O modo escuro utiliza preto, azul-marinho e ciano como cores principais. O modo claro utiliza branco, cinza-claro e azul, mantendo a identidade visual do projeto.

## Responsividade

A interface foi desenvolvida para funcionar em diferentes tamanhos de tela:

* celulares;
* tablets;
* notebooks;
* monitores maiores.

No computador, os itens de navegação ficam visíveis na barra superior. Em telas menores, eles são substituídos por um menu hambúrguer.

Os cards e as listas também reorganizam suas colunas conforme a largura disponível.

## Animações e interatividade

O projeto utiliza animações e transições para melhorar a experiência de navegação:

* entrada lateral de cards durante a rolagem;
* desaparecimento dos cards ao sair da área visível;
* efeito pulsante ao redor da fotografia;
* efeitos de elevação nos cards;
* mudança visual nos botões ao passar o cursor;
* transição entre temas;
* rolagem suave entre as seções.

A detecção dos elementos visíveis na tela é feita com a API `IntersectionObserver`.

## Como executar localmente

### Pré-requisitos

Antes de começar, é necessário possuir:

* Node.js 20 ou superior
* NPM
* Git

### Clonar o repositório

```bash
git clone https://github.com/kallyedson/portfolio-kallyedson.git
```

### Entrar na pasta

```bash
cd portfolio-kallyedson
```

### Instalar as dependências

```bash
npm install
```

### Iniciar o ambiente de desenvolvimento

```bash
npm run dev
```

Depois, abra no navegador o endereço exibido pelo Vite, geralmente:

```text
http://localhost:5173
```

## Verificações de qualidade

### Executar o ESLint

```bash
npm run lint
```

### Gerar a versão de produção

```bash
npm run build
```

### Visualizar a versão de produção localmente

```bash
npm run preview
```

## Hospedagem no Railway

O projeto está hospedado no Railway e conectado ao repositório do GitHub.

Configuração utilizada:

```text
Build Command: npm run build
Start Command: npm start
Porta pública: 8080
```

O comando de inicialização utiliza o pacote `serve`:

```json
"start": "serve -s dist -l $PORT"
```

Quando um novo commit é enviado para a branch `main`, o Railway detecta a atualização e realiza automaticamente um novo deploy.

## Como atualizar o projeto

Após realizar uma alteração:

```bash
git status
git add .
git commit -m "Descrição da alteração"
git push
```

Depois do `push`, o Railway publica automaticamente a nova versão.
